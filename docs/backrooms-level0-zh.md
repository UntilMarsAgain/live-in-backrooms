# Level 0 ——「阈值」（Threshold）

> 你在刺耳的荧光灯嗡嗡声和潮湿地毯的腐臭味中醒来。一片荒芜、绵延的迷宫在你面前铺展开来，阴险的黄色，令人抓狂的杂乱。你眨眨眼——走廊已经换了位置，却依然保持着那份空洞的死寂。
>
> 小心前行，流浪者。这里既是坟墓，也是门槛。

**生存难度：1**

- 安全
- 稳固
- 实体未经确认

常被昵称为“黄色地狱”的 **Level 0** 呈现为一座迷宫，酷似办公室或零售商店中常见的后室。它得名于墙纸病态的黄色，以及装点着该层级的遍布霉斑的地毯。

*（图片注释：Level 0 与后室的第一张已知照片）*

## 描述

那些不幸从现实柔软的褶皱间滑落的人，可能会迷失在 Level 0 畸形的通道里。这是后室的第一层，对许多误入其中的人来说，也往往是最后一层。许多人在毫无准备的情况下被困，他们蹒跚地走过一英里又一英里随机分割的房间、走廊和楼梯，每一段都同样折磨人。考虑到这段旅程令人麻木的单调，这成了一场酷刑般的苦行。

无限对人类心智而言是无法理解的。然而，它却贯穿了 Level 0 的方方面面，从建筑的种种变化到其无边无际的规模。它助长着那种令人崩溃的空虚，以恶性的谵妄侵蚀心智，慢慢将人吞噬至灵魂深处。阈限空间的黑暗回声攫住人心，喂养着疯狂。

进入者都成了流浪者，被困在孤立与偏执的海洋中，生命往往因脱水或饥饿而早早终结。

## 异常

Level 0 本质上是一座迷宫——由于该层级幅员辽阔，且迷宫会随着前行不断变化和移动，穿行其中可能极具挑战。一个人在杂乱排列的走廊里待得越久，就越可能遭遇建筑上的异常。没有万无一失的方法逃离这些令人不安的走廊；坚持不懈是活着出去的最佳机会。

### 结构

尽管 Level 0 充斥着无所不在的平庸，其建筑仍存在无数变化。以下并非详尽清单，而是最常见的结构异常。

**拱门（Arches）**

第一个显著的区别是带有拱门洞的苍白墙壁。虽然除了美观之外并无特别之处，但它们通常出现在死胡同里，或点缀着过渡房间。这些区域的地毯明显更深，使得穿行可能更具挑战性——取决于疲劳程度和地毯中积存了多少液体。有些拱门刚好够一个小个子的人休息，哪怕只是短暂地从湿漉漉的地板上获得片刻喘息。拱门房间最为稳定；它们往往不会在你身后移动或变化，这有助于流浪者确认方位。

> “……我感觉自己走了好几天——也许确实如此。很难说。这里有太多该死的雷同，过了一段时间，一切就混成了一大片黄色的模糊。
>
> 我只知道我的脚疼得超出想象，而那些拱门是我最终跌入第一层之前唯一的喘息。我的脚肿了，脱水了，鼻窦炎几周都没好。但我活了下来，不管这值不值得……”

**柱子（Pillars）**

偶尔，你会遇到巨大的柱厅——它们有时绵延数英里，并且总是以格子或网格状排列。虽然通常易于探索，但由于规模太大，会极其乏味。这些区域的地毯往往较浅，由于地面湿度较低，可能更适合入睡。许多人报告说，在探索柱厅时，身后的路径经常变化，导致柱子排列不对称，路径也可能令人困惑。建议流浪者选定一个方向并坚持走下去。

> “……那是我第三次进入零层，大概也是最长的一次。我已经尽可能做好了准备，但那种地方很难准备周全。第二天，我走进了一个柱厅，看上去是无尽排列的、间距完美的立柱——我花了十四天才找到出去的路。你可以记住他们教我们的那些技巧——朝前进的方向睡，用左手做引导——但没有任何东西能让你对这么大的房间做好准备。感谢杏仁水——很难想象没有它怎么在那里活下去……”

**洞（Holes）**

探索时，你可能会遇到深深陷入地板的坑洞。它们往往漆黑一片，光线通常只能穿透几英尺。和柱子一样，它们成群出现，形成网格状，通常很容易绕过。有些洞群可能很大或密集聚集，使坠落成为巨大的风险。掉下去之后会发生什么无人知晓；不过，没有人报告过掉下去还能活着。如果极度疲劳或脱水，应完全避开坑洞区域，因为那里会变得更加危险。

> “……我不觉得那些洞通向任何地方。人们总想给事物寻找意义——他们听到声音，感到一股牵引力，看到蓝光——各种说法。但那只是我们的头脑试图在无意义中寻找意义，把逻辑强加于不合逻辑的事物上。你很快就会明白，后室里的事物并不总是讲得通的——这里很少有逻辑或意义。它存在于这些概念之外……”

**断电区（Blackout Zone）**

断电区是 Level 0 中完全失去照明的整片区域。这些区域极难穿行，因为它们在低能见度下不断变化。一旦进入，想要逃出会极其困难，因为人很容易在黑暗中迷失。断电区的幸存者描述了墙壁上粗糙的纹理，以及缺少嗡嗡灯光的强烈寂静。这里的地板可能下陷，常常积有齐踝深的液体。如果进入，就朝第一丝光亮冲刺，或者尝试循着任何嗡嗡声前进，直到找到出口。

> “……那些该死的灯虽然烦人，但当它们熄灭时，你几乎会想念它们。你可以试着循着嗡嗡声走，但问题是声音不会待在同一个地方。有时感觉你在靠近，然后它突然又到了你身后……”

**红房间（Red Rooms）**

红房间必须完全避开，因为它们极其难以逃脱，甚至不可能逃脱。它们是 Level 0 中与整体断开的区域，一旦完全进入就根本无法突破——如同一个封闭的环。即使是靠近它们也会引起不良心理影响，如严重的幽闭恐惧和急性偏执。可以通过识别颜色变为红色来判断与红房间的距离，或者当地毯变得厚实、黏腻且非常粗糙时。另一个迹象是墙纸剥落，露出下面的深红色。最好的做法是完全避开——你应当直接转身走开。

> “……坦率地说，如果遇到红房间，能避开甚至逃出的可能性几乎为零。等大多数人意识到自己身处其中时，已经太迟了……”

**布局变化（Layout Changes）**

Level 0 的布局是一幅不断变化的荒诞建筑拼图，又被一种俗称“周边偏移”（Peripheral Shift）的效应加剧。每当不被人直接注视时，层级的布局就会扭曲、拉伸或重新排列——有时会彻底改变走了好几天的走廊。这极其令人迷失方向，更重要的是，让新流浪者和老练的探索者都感到沮丧。这种效应并非持续存在，有些区域发生的可能性较小——但这只会让黄色地狱更加令人费解。

> “……我记得我花了整整两天时间绘制一段走廊的地图。我以为自己很聪明——我标记拐角、数灯，试图建立某种参照。当我终于停下来休息，回头看来时的路时，走廊完全变了。两天的跋涉——眨眼间就消失了。你可以走几分钟、几小时，甚至几天，而就在你移开视线的下一秒，这个层级就认定那些脚步从未发生过。刚到这里时，这很难接受——缺乏连续性。我想对某些人来说这太过分了——对我几乎也是如此……”

### 噪音

Level 0 中时刻弥漫着大量环境噪音。主要来源是嗡嗡作响的灯，其音量会剧烈而无规律地波动。有时噪音大到长时间暴露会造成听力损伤。在这些高峰期间，流浪者应捂住耳朵并继续前进，以逃离声源。

流浪者还报告过其他异常声音，如模糊的低语和熟悉的呼唤声。人们还可能听到墙壁后方传来抓挠声，仿佛有什么东西在磨指甲。这些声音可能跟随人穿过长长的走廊，但从未有任何报告表明是什么引发了它们；建议忽略它们继续前行。这些听觉异常究竟是幻觉，还是未被发现的现实现象，尚不得而知。

### 地毯

Level 0 内几乎所有的地板都覆盖着紧密编织的柏柏尔式地毯。虽然在照片中呈现黄色——很可能是由于强烈的照明——但在单独观察时，颜色更接近棕褐色的米色。地毯纤维由某种未知的合成材料构成，尽管持续潮湿，摸起来却有些粗糙。虽然在整个广阔层级中纹理和色调略有变化，但地板是无缝的，由一整块连续的地毯组成。

关于浸透 Level 0 地毯的液体来源，人们知之甚少。样本显示其中含有多种液体，如盐水、微咸水、杏仁水、液态疼痛、福尔马林，甚至含有人类和非人类 DNA 的泥浆。值得注意的是，地毯不可食用，杏仁水也已受污染，因此建议即使在绝望中也不要费心去吃地板碎块。

> “……我们在阿尔法基地经常看到这种情况——人们好不容易活着逃出来，然后跌跌撞撞地走进基地，半昏迷、严重脱水、饥肠辘辘。想象一下，熬过黄色地狱，却死于某种未知的地毯传染病或纤维造成的堵塞。拜托，别吃地毯……”

### 孤立

一种恰如其分地被命名为“孤立效应”的现象，已被困在 Level 0 中的人们观察到。即使两个人并排进入 Level 0，也永远无法找到彼此。所有沟通尝试——无论是呼喊、留纸条、标记路径还是破坏墙壁——都会失败。这个层级确实是一个必须独自面对的障碍。

这种效应贯穿整个层级，随着流浪者继续前进，会造成极大的心理负担。有一个例外——一间人们能看见彼此的小房间——但 Level 0 不断变化的布局使得遇到这间房间的概率极低。

## 实体

目前尚不清楚 Level 0 是否存在实体。如果存在，它们也很可能受到孤立效应的影响。虽然没有人直接报告过，但流浪者声称看到过黑暗的身影在走廊间跟踪他们，并在穿行黄色地狱时体验到被注视的恐惧（scopophobia）。

## 入口与出口

### 入口

从现实中坠落是进入 Level 0 最常见的方式，不过在更广大的后室整体中隐藏着许多入口。

### 出口

存活足够久，找到一面闪烁的墙壁并穿过去。这将带你到 Level 1，以及仍然居住在这个世界上的人类碎片。

几乎每个流浪者都记得那个时刻——他们意识到走廊永无尽头，嗡嗡声永不停歇，他们来自的那个世界的规则不再适用。Level 0 并不是后室中最糟糕的地方——它只是第一站。尽管看起来如此，还有无数更可怕的地方在等着你，你也很可能将置身其中。

如果你已经走到了这一步，你已经跨过了门槛——欢迎来到后室。
